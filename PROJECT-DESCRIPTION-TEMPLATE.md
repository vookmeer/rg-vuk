# GARAGE SCENE

305/2023 - Vuk Vukmirovic

This scene represents the interior of a garage containing a Lamborghini Aventador, a motorbike, and a hanging light. The
scene is lit by a directional light and a point light, and the intensity and color of the lighting can be adjusted using
the keyboard. Pressing SPACE starts an animation in which the motorbike moves back and forth, representing the required
event chain.

## Controls

W -> Move forward  
A -> Move left  
S -> Move backward  
D -> Move right  
Mouse -> Rotate camera  
F1 -> Toggle cursor on/off  
L -> Toggle point light color (warm/cold)

`+` → Increase directional light intensity

`-`-> Decrease directional light intensity

SPACE -> Start/pause motorbike animation (event chain)  
Esc -> Exit
